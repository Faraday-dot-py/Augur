# Showcase videos: YouTube upload sheet

Nothing is uploaded yet. Videos 1-4 and 6 were re-rendered 2026-10-28 from the edge-artifact-free (`--kpad ext`) runs; reviewer verdicts in the experiment log (2026-10-28 entry). Videos 5 and 7 involve no scatter-field grid (adaptive analytic gravity; direct N-body plus a central-force model), so the grid-edge force artifact does not apply. For each README Showcase item: intended YouTube title, description, and the source mp4.
