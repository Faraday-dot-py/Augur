# Unexplored research directions audit (2026-10-29)

Read-only audit. No GPU job, no code change, no push. Goal: list every direction that was proposed but never run (or only scoped, or run too thinly to rule out) so the breadth-first sweep can be checked for gaps.

## Definitions (first use)

- BL = the tiled baseline model (current exact-comparison reference for the tiered line). e44b796 = commit of the closed-loop tiled tier 0 (job 4060, branch `tier0-tiled-closed-loop`), the tier-0 of record. Tier 0 = the finest tier that handles particles directly.
- err@20 = mean position error per body at tick 20 (sim units, 1 tick = dt 0.1). dE@100 = relative energy drift at tick 100. nn = nearest-neighbour distance.
- PM = particle-mesh (deposit on a grid, FFT convolve, gather). CIC = cloud-in-cell deposit. FMM = fast multipole method. RESPA = reversible multi-rate integrator. LJ = Lennard-Jones (liquid-argon-style molecular dynamics). BH = black hole scene. QOS = Slurm quality-of-service class.
- GPU-h = GPU-hours (one H200). Cost figures are taken from the logs where one exists, otherwise a rough estimate marked "est.".
- Core requirements (docs/paper/core-requirements.md:3-6): generalization (any particle sim), tileable, O(N), interpretability. Column "touches" uses the words gen / tile / O(N) / interp.
- Priority 1-5 follows docs/debugging/priority-system.md:14-31 (3 = normal; +1 if the answer changes a decision, +1 if it unblocks other work, -1 above 4 GPU-h, -1 for no written pass/kill; capped at 4 without a user deadline).

## Status classes

- NEVER-RUN: proposed, no run, no code.
- SCOPED-ONLY: designed or pre-registered or code written, never executed (or gated and the gate never opened).
- RAN-BUT-INCONCLUSIVE: ran, but one seed, low power, wrong horizon, confounded or stopped by an early probe, so it cannot rule the idea out.
