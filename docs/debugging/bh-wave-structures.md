# BH collapse: wave-like structures and spin (PRE-REGISTRATION, written before any run)

Date 2026-10-22, branch `bh-wave-structures` (from `exp-e-proposed-1e8`). Seed 4738. Analysis scripts only; model untouched.

Scene (from `scatter_bh.py` / `scatter_bh_1b.py`, read before registering): N unit-mass bodies, Gaussian sigma 8 clipped to +-29, per-component IC speed std 0.3*sqrt(N/(4*sigma)), then clamped to 0.99c; c = 10, dt = 0.1, softened force eps = 0.5, G = 1, relativistic momentum state p (v = p/sqrt(1+p^2/c^2)), grid 128^2 on extent 64 (cell h = 0.5 = eps), mesh-only (pair term off). Horizon R_s = 2N/c^2.

## Hypotheses and confirm / reject criteria

| id | hypothesis | CONFIRMED if | REJECTED if |
|---|---|---|---|
| H1 | Physical: orbit-crossing / shell-crossing of a near-radial, speed-capped collapse (bodies pass through the core at ~c and fly out as shells; radial oscillation, phase wrapping) | exact (truth) sim at small N shows the same shells with the same radii/time; 1-D spherical-shell integration with the same softening, cap and mass profile reproduces shell radii vs time within ~15% | no structure in truth, or reference radii/period disagree |
| H2 | Speed-cap bounce: shell front travels at c (1 unit/tick) | shell front radius slope vs tick = c*dt = 1.0 +-10% in truth and model | slope differs |
| H3 | Mesh artefact: structure scale locked to grid cell h = 0.5, box +-32, FFT periodicity | structure radii/wavelength change when the grid or extent changes at fixed N, or plain PM at same grid shows it while exact truth does not, or radii cluster at multiples of h | radii independent of grid |
| H4 | Learned-model error (U-Net potential term) | model shows structure that plain PM (non-learned) at same grid does not, or model structure differs from truth where PM matches | PM equals model |
| H5 | Shot noise: structure amplitude drops with N (1e4 -> 1e5 -> 1e6) | azimuthal power in rings relative to Poisson floor falls as N grows | ring contrast N-independent (converges to a physical limit) |
| H6 | Edge: reflection/pile-up at the +-32 box (zero force outside) | rings change at r ~ 29-32 or time shift matches round trip to the edge | no effect of edge on ring radii at r < 25 |
| Q4 | Spin: IC has net L = 0 (isotropic random velocities, momentum subtracted), so no net spin-up; rotation rate stays ~0 in truth and model. A rotating-IC variant should spin up as 1/r^2 (L conserved) in truth; model conserves L only if the mesh force is central (momfix removes net force only) | L(t)/L_scale < 1e-2 truth; rotating IC: L drift model vs truth <5% | L grows from nothing |

Quantities: radial density profile rho(r, t), shell radius vs tick (local maxima of rho(r)), azimuthally averaged 2-D power / ring contrast, energy E(t), virial ratio 2K/|W|, L(t) about the centre of mass, rotation rate Omega(<r) = <L_z>/<r^2> within enclosed-mass radii.

Constraint check: generalization, O(N) and interpretability untouched (analysis only); pp=2 off as in the 1e8 runs; truth E(t) is the reference, not E(0).

Definitions. PM = particle-mesh: own non-learned code, CIC (cloud-in-cell) deposit on a 128^2 grid, extent 64, FFT convolution with the exact softened potential kernel, central differences, momentum fix, same integrator, 1 step per tick (pm128s4: 4 substeps per tick; pm256: 256^2 grid). truth4 = exact fp64 all-pairs, 4 substeps per tick (as `rollout_torch`); truth1 = exact, 1 substep per tick. "ref" = axisymmetric reference: 2e4-2e5 representative bodies, force from azimuthally averaged mass rings with the same eps = 0.5 and the same relativistic integrator, L conserved exactly, N enters only as a weight so any N runs on CPU. It is not a 1-D shell code: the system is planar with a 3-D-form force, so there is no shell theorem, hence the ring table. Seed 4738 (plus 9000 at N=1e4). Scene: N unit-mass bodies, Gaussian sigma 8, cold (per-component speed 0.3*sqrt(N/(4*8))), c = 10, dt = 0.1. r50 = radius enclosing half the bodies about the centre of mass. EMD = earth-mover distance between cumulative radial profiles (length units). omega_net = L_z / sum r^2 inside r50.

## What the frames show (unbiased reviewers, before theory)
Existing 1e8 grids: collapse to a bright core by tick ~18, thin round shells expanding outward, filament/caustic web at ticks 18-36, then a smooth halo with a few thin sharp circular arcs near the core that stay at the same radii from frame to frame (lensed video, steps 72-126); no square or grid-aligned structure except the clip-line rim at tick 0. 100k exact-force runs: irregular tangles and rounder shells re-forming with period of order a few thousand steps (capped run), clean expanding concentric rings in the first 20 steps (8-substep run). New N=1e5 comparison: all three arms collapse by tick ~19, emit one thin near-circular shell (visible tick ~38), then a compact elongated core; model_new's core is elongated vertically where truth and PM are horizontal, and it is broader. In radius-time maps truth, PM and the reference carry several thin parallel streaks behind the main front; the model has almost none and its core band widens to r ~ 10 by tick 150.

## Q1 and Q2: why the structures form, and are they in truth?
They are in exact truth. Radius-time maps (`docs/debugging/bh-wave-figs/spacetime_n1e5_s4738.png`) show the same pattern in truth4, truth1, all PM variants and the mesh-free axisymmetric reference: (i) one bright outgoing front leaving the core at tick ~25-30 (the shell in the videos), (ii) a family of thinner parallel diagonal streaks behind it from tick ~40 (a fan of caustics), (iii) a persistent bright band at r < 3. Interpretation, supported by agreement of four independent integrators including a mesh-free one: orbit/shell crossing in a cold collapse. Bodies fall through the softened core at near c, overshoot, and different initial radii return at different phases, producing nested outgoing shells that wrap in phase space. The outermost front moves at 0.86-0.89 r/tick at N=1e5 and 0.90-0.95 at 1e6-1e7 (c*dt = 1 r/tick): saturated by the speed cap, not reflected by it. First-front radius agrees within 1.3 units between truth, PM, model and reference at ticks 20-70 (tick 50, N=1e5: 32.1 / 32.4 / 32.6 / 32.1; N=1e6 PM 33.6, model 34.1, reference 33.6); collapse tick (minimum r50) is 13-16 in every arm.

Mesh/grid (H3) and edge (H6) are not the origin. PM at 128^2 and 256^2 (cell 0.5 and 0.25), 1 and 4 substeps, and the exact sim at dt=0.1 per step give the same front and collapse tick; the reference has no grid. Bodies beyond r = 32 (11-21% by tick 100) feel zero force in PM/model, but front radii and collapse times agree with the exact sim, which has no box. The late core is slightly hotter with a 1-substep step (r50 at tick 150: truth4 1.6, truth1 2.2, pm128 2.2, pm128s4 1.7): an integrator-step effect, not a mesh effect.

Convergence with N (H5): ring/streak contrast above the Poisson floor in truth4 is 0.074 (N=1e4), 0.087 (3e4), 0.106 (1e5); PM128 0.115 at 1e6 and 0.127 at 1e7; reference 0.15 (1e5), 0.29 (1e6), 0.34 (1e7). The excess does not fall with N; it rises, and the grid-free continuum limit is the sharpest. So the structure is a physical limit, not shot noise; at N=1e4 shot noise (floor 0.26) hides it. Caveat: one seed per N, two at 1e4.

Artefact: the learned model's departure from truth. At N <= 1e5 model_new and model_old have almost no secondary streaks and the core drifts off the centre of mass: offset reaches 6.1 at tick 150 (N=1e5; truth 0.19, PM 0.17), r50 grows 2.2 to 10.4 (truth 2.2, PM 2.8), per-body |l| 9.3e3 vs 1.3e3. EMD vs truth at tick 150: model_new 7.0 (1e5), 8.0 (1e4), 8.8 (3e4); model_old 3.7 / 4.6; PM 0.8 / 0.35. The drift shrinks with N: model_new r50 at tick 150 is 4.75 at N=1e6 (reference 1.5, PM 2.2), and the 1e8 videos show no such drift (earlier record: core r45 within 15% of 1e6). Not isolated: why it drifts. Candidates consistent with the numbers: zero force outside the +-32 box while the momentum fix subtracts a global mean (17-24% of bodies are outside by tick 150); the ghost edge closure worsens it (model_new > model_old at every N); Exp E was trained at total mass <= ~1e3. Streak spacing is of order 3-5 length units, far larger than the cell h = 0.5 and eps = 0.5, and the same in the grid-free reference: no grid-locked wavelength (a spectral-peak period estimate of 14-40 ticks is noisy, 2-5% of power, not quoted as a result). Unverifiable at 1e8-1e10: truth is impossible; substitute is exact to 1e5, PM to 1e7, reference to 1e8, model to 1e6 plus the recorded 1e8. The thin fixed-radius arcs in the 1e8 lensed video were not individually matched.

## Q3: correct versus physics?
Against exact truth and the axisymmetric reference. Correct: collapse time, outgoing front trajectory (within one cell), existence of the fan. Reference vs truth4 at N=1e5: EMD 0.04 (tick 25), 0.30 (50), 0.66 (100), 0.74 (150) length units, versus 0.3-0.5 between two truth substep settings, so the mean-field limit is within integration noise until tick ~50-100 and slowly departs (two-body relaxation, omitted from the reference). Energy per body (relativistic KE plus softened potential, N=1e5): truth -3999 at tick 0 to -3507 at 150 (12% drift: KDK at dt=0.1 near the core), PM to -2268 (43%), model_new to -836 (79%). Virial proxy p.v/|W| goes 0.27 to 0.78 (truth), 0.82 (PM), 0.94 (model); it never nears 1 because bodies are at ~0.99c, so it is a diagnostic, not a test. Unverifiable: closed-form caustic radii; I did not derive one (softened planar force, relativistic momentum, clipped Gaussian IC). The reference shares truth's integrator, so it checks the mesh and the model, not the integrator.

## Q4: spin
The standard IC (isotropic random velocities, mean subtracted) has L ~ 0: L/sum|l| = 1.7e-3 at N=1e5, omega_net -2e-3 at tick 0 and |omega_net| < 0.04 afterwards in truth, so there is nothing to spin up. Exact truth conserves L to 5e-6 of sum|l|; PM 2.7e-2 (mesh force not exactly central); model_new 0.25 (N=1e5) to 0.43 (N=1e4): the model does not conserve L, and the offset core carries spurious angular momentum (|l| per body grows 7x). Rotating IC (solid body 0.25 rad/time added): truth at N=1e5 has omega_net(r50) 0.09 at tick 0, 0.31 (10), 0.36 (25), 0.22 (150) while r50 falls 9.4 to 1.9; net L is conserved exactly. The rise is ~4x, not the 1/r^2 ~ 24x of a coherent rotating cloud, because net rotation is ~10% of the random tangential motion (omega_abs ~ 4 vs omega_net 0.36) and v_t <= c. PM follows truth (0.32 at tick 25, 0.20 at 150, L within 5%). model_new: omega_net 0.26 (10), 0.14 (25), 0.04 (100), 0.002 (150); L 0.24 to 0.69 (+186%) at N=1e5. It spins up initially like truth, then loses the rotation and creates spurious L as the core drifts. What spin can mean here: a planar softened-Newtonian system with a speed cap and relativistic kinetics, no field equations. The speed-cap "black hole" is a kinematic definition (escape speed > c): no horizon, frame dragging or Kerr spin exist; only classical angular momentum of the body distribution is measurable.

## Verdicts
- Q1 why: CONFIRMED real physics (cold-collapse shell crossing, speed-capped front); mesh/edge ruled out as origin; the model's departure is an ARTEFACT at N <= 1e5 (core drift, cause not isolated). Confidence high (physics), medium (artefact cause).
- Q2 in truth: CONFIRMED at N = 1e4-1e5 exact; UNVERIFIABLE at 1e8-1e10 (substituted by scaling). Confidence high / medium.
- Q3 correct: CONFIRMED for collapse time, front, existence of the fan, mean-field limit; model fan amplitude, energy and late core are an ARTEFACT; closed-form caustic radii UNVERIFIABLE. Confidence medium.
- Q4 spin: IC has L = 0, no spin-up expected or seen; rotating IC spins up in truth and PM (~4x, bounded); model fails to conserve L at N <= 1e5 (ARTEFACT); Kerr spin not applicable. Confidence high.
