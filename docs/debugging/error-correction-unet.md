# Error correction for U-Net grid models used autoregressively (research only)

Uncommitted. No code run. Web claims come from search snippets/abstracts unless marked "read" (fetched text). UNVERIFIED = not checked in source text or not tested on Augur.

## Augur's net (read from scripts/scatter_field.py:25-50, scatter-field-architecture.md)

- `UNet`: 3x3 conv + GELU blocks, no normalization layer, `F.avg_pool2d(2)` down, `nearest` up, concat skips, 4-5 levels, **zero padding**, linear (unbounded) output conv.
- Output = potential (`--potential`, a = -grad phi by finite difference) or 2-channel acceleration; previous output field fed back as input (`recurrent`); `momfix` subtracts mean dv. Tokens outside the grid get 0 force; mesh weight tapered by `edge_weight` near the edge.
- Observed failures (scatter-correction-research.md, mechanisms 5, 8): (a) a0 channel 17 -> 30 -> 65 -> 181 -> 1150 over ticks 21-24 (x2-6/tick) after training to k_end=20; Exp E (50-100-tick windows) does not blow up in 1e4 ticks. (b) edge spike +4960 at x=30.5 vs ~120 exact, deterministic, moves with the grid edge. (c) dE drift; any fine-tune broke nr100 dE@1000.

## Mapping failure -> U-Net mechanism -> literature

1. Runaway past the training unroll = recurrent positive feedback + exposure bias. Mechanism: the loop (field_t -> net -> field_{t+1}) has no contraction guarantee; error propagator is a product of step Jacobians and can grow transiently even if each step is contractive (alphaxiv 2605.08856, read: UNet 1D KdV nMSE 1.9 -> 6.9e-2 at step 5000 with commutator+normality penalties; 2D UNet barotropic RMSE 6.01 vs 0.665; SST UNet 3x). Literature fixes: train on longer unrolls (GraphCast 12-step curriculum, backprop through all steps, arXiv 2212.12794; Solver-in-the-Loop 1-4 unrolled steps up to 40%, arXiv 2007.00016); pushforward/noise (Brandstetter arXiv 2202.03376); input noise (Stachenfeld arXiv 2112.15275: sigma=0.01 loses one-step accuracy, gains rollout stability; GNS arXiv 2002.09405 noise-corrupted inputs). Caveat: in PDE-Refiner's own KS tests pushforward did NOT help (read, ar5iv 2308.05732), so it is not a given. Augur already tried closed-loop relabel (negative); that is a different, expensive variant of unroll/pushforward; plain unrolled loss to k>=50 (what Exp E did) is the cheap version and the only one with positive evidence in-repo.
2. Edge spike = zero padding. Mechanism: conv zero padding gives border cells a different input statistic than interior; one 1D U-Net paper reports errors born at boundary points and amplified in rollout (PDEformer app., arXiv 2402.12652, via search snippet). Fixes used: periodic/circular padding when the domain is periodic (arXiv 2601.08404 snippet), but that is equation-specific (same source) and wrong for Augur's open domain. Open-domain fix = guard band / replicate or extrapolated halo, which Augur's own review already ranks first. Because the spike is present in the kernel gradient alone (max 2074) and U-Net alone (2460), padding is not the only source; the finite-difference gradient of phi amplifies any border discontinuity.
3. Potential head + finite-difference gradient amplifies high k. a = -grad phi multiplies spectrum by k; grid-scale error in phi becomes O(1/h) error in a. Related: spectral-bias argument (Chattopadhyay et al., arXiv 2304.07029 abstract, read: all architectures learn large scales, neglect small scales, error propagation unstable; fix FouRKS = Fourier-regularised loss + RK integration; Jacobian eigen-analysis details UNVERIFIED, PDF not parsed). PDE-Refiner (read): MSE-trained U-Net neglects low-amplitude (often high-k) content; 3 refinement steps, sigma_min^2 = 2e-7 (KS) / 1e-3 (Kolmogorov), +~10% rollout time on 2D flow (9.66 -> 10.66 s), 4x inference cost (4.04 -> 16.53 s). SGNO (arXiv 2602.18801 snippet): truncation + smooth mask on the forcing path stops high-k feedback growth. JAWS (arXiv 2603.05538 snippet): global spectral norm / low-pass stabilises but over-smooths (damps shocks) -> local strength preferred.
4. Down/up-sampling aliasing. avg_pool + nearest upsample is not alias-free; CNNs do not learn adequate anti-aliasing (arXiv 2102.07757 snippet; alias-free convnets arXiv 2303.08085 snippet; neural-operator aliasing, NeurIPS 2023 poster 72712). No source found linking this to rollout blow-up in U-Nets directly: UNVERIFIED for Augur. Nearest-upsample creates 2^l-periodic block artifacts; Augur notes the net is equivariant only to shifts by 2^levels cells, so mesh-phase artifacts are plausible (review mechanism list "mesh phase").
5. Normalization. Augur has none, so GroupNorm/BatchNorm risks do not apply. Note PDE-Refiner/PDEArena modern U-Nets use GroupNorm (read). No source found tying norm layers to rollout instability. Adding one is not recommended without evidence (also breaks tile-size invariance if it normalizes over the spatial extent: UNVERIFIED reasoning).
6. Skip-connection error pass-through. Concat skips carry level-0 features (incl. the fed-back field) straight to the output conv, so grid-scale error is not damped by the bottleneck. No direct citation; "residual/increment targets" are the common mitigation (arXiv 2601.08404 snippet). Treat as hypothesis; testable by zeroing/low-passing the level-0 skip of the fed-back channels.
7. Unbounded outputs. Augur: linear output conv, no cap on a0. Prior in repo: `tanh*max_correction` / `max_flow` bounding worked as a hard bound on the token model (experiment-log ~L146); contact path uses FMAX=40 clamp which "masks, does not fix" (review). Literature: NeuralGCM fixed a specific drifting variable (mean log surface pressure) by constraining it and removed a stochastic encoder input (arXiv 2412.11973 snippet). A soft bound (tanh/softcap with learned or data-quantile scale) is a mild prior, not a hard-coded conservative force; but it only caps magnitude, it does not remove the feedback loop.
8. Recurrent hidden-state drift. Third-party benchmarks report GraphCast/AIFS amplify noise exponentially early, Aurora/Pangu/SFNO saturate (arXiv 2605.30184 snippet, third-party); U-Net in a climate benchmark showed artifacts (snippet, unnamed benchmark). NeuralGCM dropped stochastic encoder input for stability (above). For Augur, D3 in the review (cold-reset recurrent field every 20 ticks) already isolates this; do that before any architecture change.
9. dE drift. U-Net outputs a non-conservative field unless a = -grad phi is exact and the integrator symplectic-ish. Potential head already gives curl-free force (mechanism curl probe); remaining drift = time-dependent phi (recurrent state, mesh phase) and integrator. Soft priors: energy-drift penalty over multi-step windows (loss, not architecture; already a "soft energy/restitution loss" open item). ML turbulence closures: online-unstable closures traced to backscatter; post-hoc cancelling gives over-diffusion (Guan/Subel/Chattopadhyay/Hassanzadeh, arXiv 2201.07347 snippet) - analogue of a clamp that stabilises but dissipates.
