# Close-pair design proposals for the scatter field (2026-10-15, research only)

Research and design only. No training, no GPU, no code changed. Every claim is read from code or an existing write-up (cited); anything not measured is marked UNTESTED. Line refs are `scripts/scatter_field.py` (sf) on master 5104e37.

Definitions (first use): N = bodies per scene; nn = distance from a body to its nearest neighbour; err@k = pooled mean per-body position error at tick k (sim units, 1 tick = dt 0.1); dE / dL = relative energy / angular-momentum drift; nr100 / bh300 = the 100-body / 300-body (black hole) conservation rows of the regression harness; ab = 10-200-body scale-init eval scenes, cl = cluster eval scenes (seeds 9000/12000); CIC = cloud-in-cell (bilinear 4-node) deposit/gather; FFT = fast Fourier transform (grid convolution); P3M = particle-particle particle-mesh (mesh handles far field, an exact pair term the near field); h = grid cell size 0.5 (grid 128, extent 64); pp = exact-pair radius (2); knn = neighbours kept per body (16); eps = gravity softening 0.5; MLP = multilayer perceptron; U-Net = the grid network; momfix = mass-weighted mean-acceleration subtraction (sf:482-484); rel_rms = rms|a_model - a_exact| / rms|a_exact|; "Exp E" = checkpoint `E_ms_kp_pot_v_g128`; "ctl" = same architecture, from scratch, same schedule (the pairfull control of long-rollout-root-cause.md).

## 1. What the close-pair path is today (verified in code)

Variant `ms_kp_pot_v_g128` (`train_scatter_field.py:39`): kernel=True, pp=2.0, split=True, potential=True, verlet=True, prior=False, knn=16. Force on a body = `gather(-grad(U-Net potential) + ak)` (sf:445-473) + `pp_acc` (sf:481) with momfix after (sf:482-484).
- `ak` = learned isotropic kernel K(r) = kmlp(r) x split, convolved with the CIC-deposited density by FFT (sf:183-206). Split = 1 - (1-u)^2, u = (r/pp)^2 (sf:192). Zero-init output, so Exp E starts with no analytic gravity anywhere (prior=False); `prior` mode (sf:65, 189-190, 213-216) swaps in analytic softened gravity for both kernel and pair complement together and cannot be set for the pair term alone.
- Pair term (sf:208-217, 275, 375): for each body the knn nearest candidates from a 3x3 cell window of pp-sized cells; acceleration = sum_j w(r) d_ij / r with w = ppmlp([r, log(r+0.05)]) * (1-u)^2 * m_j. ppmlp is 2-64-64-1 with zero-init output (sf:83-86, 105-113).
- Consequences read from the code: the pair branch is a scalar along the line of centres, a function of r and linear in m_j only. It is therefore already central and reciprocal (m_i a_i = -m_j a_j for a mutual pair) by construction, and sees no velocity, no m_i, no third body. Reciprocity breaks only when j is in i's list and i not in j's (knn truncation); momfix then spreads that residual over all bodies. Flag: this existing structure is a hard-wired central/reciprocal pair law, the same property the no-hard-coded-conservative-forces rule objects to; only the grid branch (momentum channels in, U-Net) can express non-central or velocity-dependent forces today.
- Density bound today: candidates per body <= 9 x M, M = cell cap. With `cap=int` it is a hard static bound (sf:241-251); the default graph path sets M from max occupancy at capture (sf:365, 428), `pp_acc_adapt` caps at 48 (sf:283). Pair-stage cost per body is therefore 9M distance tests plus k=16 MLP evaluations (~4.3k multiply-accumulates each), independent of local density beyond M; excess candidates are dropped (accuracy loss in dense cores, as today).

## 3. Constraint key (every recommendation is checked against these)

O(N): cost per body bounded independent of local density (state the bound). Tileable: no global reductions beyond what exists, positions enter only through the global grid phase and relative offsets. Generalizes N/scale: features in cell units or relative, no N-dependent constants. Interpretable: the learned object can be read as a pair law or a named correction. Learned dynamics: no analytic force beyond the allowed `prior` mode. Non-conserving OK: nothing forces energy/angular-momentum conservation. Momentum: momfix kept; any new antisymmetry is derived, not imposed.

## 4. Recommendations, ranked

### R1. Exact discrete mesh-pair complement (mesh-emulating subtraction)

Mechanism. The pair term currently adds to whatever the mesh already gives for that pair. In P3M the pair term should be (true pair force) minus (what the mesh pipeline itself produces for that pair). Today the "minus" is either folded into ppmlp as an r-only average (Exp E, prior=False) or an analytic continuous mesh share (prior mode, sf:213-216), neither of which equals the CIC + FFT + central-difference + CIC pipeline for a given pair: it depends on both bodies' sub-cell phase and the pair orientation. R1 computes that pipeline's response for each listed pair exactly. For pair (i, j): body j deposits m_j on its 4 CIC nodes (weights w_c); the potential at any node is sum_c w_c K(node - c) x in_scale x m_j; the grid gradient is the 2h central difference of that potential (sf:405-409); body i gathers it with its 4 CIC weights. That is 12 distinct potential sample points x 4 source nodes, ~50 lookups of K at integer node offsets (|offset| <= ~7 cells for r <= pp). The offsets table (~15 x 15 entries) is evaluated from kmlp once per tick (the same K sf:183-193 already builds on the 2G x 2G FFT grid, so it can be indexed there). New pair term: P_ij = win(r) * (F_hat(r) - M_ij) * m_j along r_hat for the in-range pairs, with M_ij the exact mesh contribution of j onto i (U-Net part excluded, only the kernel part `ak`), F_hat = ppmlp output reinterpreted as the total pair law (a clean 1-D function of r with no mesh bias folded in). In-range total = (1-win) M_ij + win F_hat, so a pair at r < 0.5 (win >= 0.88) gets the clean F_hat and the phase-dependent mesh error is cancelled to first order.
Hooks: new `mesh_pair_acc` called from `_pair_w` callers (sf:275, 281, 375) and the adaptive path `_pp_force` (sf:278-281) with the kernel table from `_kernel_fft` (sf:183-193); ppmlp semantics change in `_pair_w` (sf:208-217). Window unchanged for the first test (no new knob).
Why nn<1: the sub-grid mesh response is an absolute error of ~0.1 in acceleration for pairs at r < h (analytic-complement probe +16% at r .1-.5; CIC-gradient between nodes of a kernel that the window only suppresses as ~2u; reasoning from sf:161, 183-206, UNTESTED numerically) and depends on phase (34% of E's squared force error, 59% for nn>.5, where nn .25-1 holds 64% of E's squared error). An r-only ppmlp cannot express phase, which is why it plateaus (gap doc section 3). Because the cancellation is deterministic, rollout training cannot degrade it, only F_hat and the far mesh are trainable (addresses root cause 3 for the in-range part).
Not addressed: far-mesh handoff error at r in [pp, 3pp] (analytic P2 nn 2-4 bin 8.9%; trained E 2.9%), the U-Net's own phase noise, the blend zone r in [1, 2) where (1-win) is 0.44-0.96 and mesh error survives, velocity dependence.
Constraints: O(N) yes: <= knn=16 pairs x ~50 lookups per body, bounded by the same candidate cap M as today (adds ~800 gathers per body vs ~69k MACs for 16 ppmlp evals; memory-bound but fixed; estimate UNTESTED). Tileable yes (offsets in cell units, global grid phase as the mesh already uses). Generalizes yes (cell-unit offsets, kmlp features already have a `cu` cell-unit mode, sf:107-108). Interpretable improved: F_hat is directly the pair law and the K table is the mesh law. Learned dynamics yes: F_hat and K both learned; the subtraction is the model's own operator, not physics. No hard-coded conservative force: the pair direction stays scalar along r_hat exactly as today (no new constraint added; the existing centrality is inherited, see section 1). Non-conserving yes (F_hat arbitrary sign/shape). Momentum: the mesh pair response is antisymmetric (symmetric CIC weights and K, antisymmetric central difference), derived and UNTESTED; momfix kept.
Cost/complexity: new ~60-line function plus a unit test (complement + mesh equals F_hat for an isolated pair at 64 random phases, momentum sum zero); inference cost: UNTESTED, harness timing row (TIME_TOL 5%) may fail and must be reported.
Evidence supports: two-body probe (analytic P2 +10..16%), phase share (34%), D6 (E not shift-equivariant at sub-cell, 6-10% at half a cell), 4-phase averaging cut err@20 by 39% (root-cause), B/E same arch gap shows learnable accuracy. Undercuts: the two-body bias of the trained E is -20% (opposite sign to the analytic +16%), so E's learned parts over-correct or compensate something else (integrator, hedging) and R1 would not touch that; nn<.25 has only 11% phase share; ceiling -37% err@20.
Step 0 (eval-only, no training, 1 packed GPU job): (a) attribution probe on Exp E two-body: radial force at r = .1-2 split into kernel-only (`ak`), U-Net-only, pair-only, momfix; (b) analytic diagnostic: analytic K (prior kernel) + analytic F + exact discrete complement, no net, vs P3M pp=2 analytic (13.6 / 13.8 / 12.0% at nn <.25 / .25-.5 / .5-1) on the root-cause scenes (expB seed 9300, cluster 9200). [MEASURED 2026-10-16, job 3646, experiment-log.md: prediction met; the literal formula P_ij = win(F_hat - M_ij) double counts with the split kernel; use F_hat - M_ij (full) or base + win(a_cont - M_ij); nn<1 error 13.6/13.8/12.0 -> 3.7/3.4/4.2 % full; Exp E attribution: kernel -18..-27 %, U-Net +47..93 %, pair +51 % at r<.5, total -20 % at r=.1.] Prediction: nn<1 bins fall by >= 40% (to <= ~8%; the far-mesh part stays). Kill R1 if (b) falls < 25% in the .25-.5 bin: then the mesh pair response is not the dominant in-range error.
Predicted effect (training arm, UNTESTED): ab err@20 -15% vs ctl (range -5..-30%, ceiling -37%), nn<1 force rel_rms -20%, phase share of nn<1 squared force error halved; cluster err@20 -5..-15% (ceiling -30%).
Pass / kill: arms = ctl vs R1 only, from scratch, identical loop (2000 scenes x 30 ticks, batch 16, k 4->20, cosine lr 1e-3, 4000 it, squared loss as in the pairfull ctl so numbers compare), seeds 4738 and 4739, packed in one job (feedback: package tests together). Pass: ab err@20 <= 0.85 x ctl on both seeds, cl err@20 <= 1.0 x ctl, nn<1 force rel_rms <= 0.85 x ctl, and the sub-cell phase share of nn<1 squared force error falls >= 40% (mechanism check; improvement without it is labelled unexplained). Gate rows: run `scatter_regress.py compare` vs frozen Exp E; any dE/dL row failing counts as failing the gate (ctl itself fails bh300 dE@100 .048 -> .356 and dL .30 -> 3.13, so "positive vs ctl, gate FAIL" is a possible and honest verdict, as for pairfull). Kill: err@20 ratio > 0.95 on either seed, or force error not improved >= 10%.
Falsified by: Step 0(b) showing the analytic exact-complement leaves nn<1 error unchanged; or phase probe showing nn<.5 error of ctl is phase-independent bias (the cancellation would then have nothing to remove).
Risks: Verlet evaluates the force at predicted positions (sf:504-506), complement uses the same positions (fine); gradient through K table adds a path from the pair loss into kmlp (UNTESTED effect on dE); edge-of-grid nodes have zero weights (sf:138) so the complement must use the same validity mask or it subtracts a force the mesh never gave; extra cost may fail the timing row.

### R2. Shape-normalised pair law with bounded log-correction (stacked on R1)

Mechanism. Reparameterize F_hat of R1 as F_hat(r) = a * r (r^2 + s^2)^(-(p+1)/2) * exp(L tanh(g(r)/L)): a learnable envelope (3 scalars a, s, p initialised at softened gravity a=1, s=eps, p=2, the already-allowed prior) times a bounded multiplicative correction g (ppmlp, zero-init, input [r, log(r+.05)] unchanged), |log factor| <= L. Exact regression target for g is O(1) and slowly varying, like the CF model's f(log d)/(d^2+1) whose force error under direct supervision is 0.09% versus 0.71% for ppmlp-in-scatter (gap doc E2). The bound caps how far training can move the pair law from its envelope. For a sim with a different pair law the three scalars move (a soft prior, not a gravity constant), and the bound L is a learnable scalar with a floor, so non-gravity forces remain reachable; sign changes (repulsive cores) are not representable by the multiplicative factor, so an additive zero-init branch g2 * win with an L2 penalty on its output (soft prior, allowed) is kept for them.
Hooks: `_pair_w` (sf:208-217) and the ppmlp definition (sf:83-86); depends on R1 because the current prior complement assumes an analytic mesh share (sf:213-216) that the learned kernel of Exp E does not have, so the envelope is only meaningful as the total law inside R1.
Why nn<1: protects the part of the error that is training damage (root cause 3: E's first step 0.94% -> 5.7%, -20% bias at r=.1 where B has -2%) in the one region where the exact answer is a known family, limiting how far a rare-close-pass gradient can bend F_hat.
Constraints: O(N) unchanged (same pair list, +3 scalars). Tileable, generalizes yes (scalars, cell-independent r). Interpretable improved (a, s, p readable: recovers a softened power law and the residual shape). Learned dynamics: prior mode style initialisation only, scalars trainable; analytic gravity is the init, not a fixed term. Non-conserving: additive branch + trainable L. No new conservative constraint. Momentum unchanged.
Evidence supports: CF envelope result; pairfull0 -> pairfull degradation; B vs E. Undercuts (important): direct force supervision improves the analytic base (0.69% -> 0.11%), so the degradation is caused by the rollout loss, not by the parameterization; Euclid loss already restored the median body error to B level (loss-function-tests.md: .0049 vs B .0043); prior-mode variants lost to ctl under the squared loss (+73..105% err@20) although their force error was lower; if the data want a correction bigger than L the bound hurts. So R2 is a guard-rail with weak direct evidence.
Pass / kill: single change vs the R1 arm (same schedule, seeds 4738/4739); if R1 fails, R2 is not run (it needs R1). Pass: nn<1 force rel_rms after training <= 1.5 x its value at initialisation (pairfull0 went 7x), ab err@20 <= 0.9 x R1 on both seeds, median step-20 body error not above R1's. Kill: the bound binds on > 20% of the r < 0.5 evaluation grid (the data reject the envelope), or err@20 >= R1's.
Predicted effect: 0..-10% err@20 beyond R1 (UNTESTED); main value is lower variance of the near-field force across seeds and robustness under the squared loss.
Risks: three more scalars to learn with Adam first-step jumps (the lr-warmup agent's remit, not proposed here); L is a new hyperparameter (made learnable to avoid a sweep); additive branch can reabsorb the freedom the bound removes.

### R3. Gated neighbour-context pair branch (two-level, fixed-size local graph)

Mechanism. Replace the scalar pair weight by a two-stage message pass over the same k=16 list: stage 1 message m_ij = phi([r, log(r+.05), v_rel along r_hat, v_rel perpendicular, m_i, m_j]) -> 2 numbers (radial, tangential) in the pair's local frame; stage 2 pools sum_j m_ij with a per-body summary (count within pp, sum of window weights) through a second MLP to a 2-vector acceleration correction. Output layers zero-init and multiplied by win, so the model starts equal to today's. For central, reciprocal, v-independent sims the tangential channel and v dependence train to ~0; for contact/drag/magnetic-type pair forces they carry the physics. A potential-plus-remainder reading: radial part = -dV/dr of a learned V (equal to the current scalar law), the remainder a free learned term with no penalty (the user's rule allows soft penalties only; none is added, because a penalty toward conservation would contradict the energy-similarity rule).
Hooks: `_pair_w` (sf:208-217) widened to take (d, v_i - v_j, m_i, m_j) and return a 2-vector; plumbing of vel and mass into `pp_acc*` (sf:275, 281, 375). First-layer widening only; second stage is a per-body MLP over a pooled sum.
Why nn<1: D4's frozen-E residual with exactly these inputs (dx, dv, r, softened force vector, K=8) explained 44% of the one-step force error of near bodies while the same net with neighbours zeroed explained ~1%: the error is a function of the local pair configuration including velocity (spurious v dependence 9-33% for nn<1). This branch can cancel it at the source and, trained in the loop from scratch, is not a post-hoc patch.
Constraints: O(N) yes (k=16, +~2x pair MLP cost: 6 input features, plus one per-body MLP; bounded by the same cap M). Tileable yes (relative quantities only). Generalizes N/scale yes; generalizes rules better than today (velocity and mass dependent pair interactions become representable, currently only through the grid). Interpretable: each channel can be probed (partial dependence on v_rel, m). Learned dynamics: yes, fully. No hard-coded conservative/central/antisymmetric structure; removes the central/reciprocal hard-wiring noted in section 1. Non-conserving yes. Momentum: no longer automatic for non-reciprocal outputs, so momfix (kept) carries it; |dP| must be reported (D4 saw |dP| 41-130 without momfix).
Evidence supports: D4 one-step -44%; velocity-dependence probe; requirement 1 (any particle sim). Undercuts (strongly for accuracy): D4 rollout ratio .98-1.0 with both method and control failing nr100 dE@1000 (.020 -> .21), i.e. any extra unconstrained acceleration term broke energy; gravity is exactly pairwise, central and v-independent, so this branch can only fit E-specific error on gravity data; the nn<1 force ceiling is -37% err@20.
Pass / kill: from scratch vs ctl, seeds 4738/4739, same loop. Pass: ab err@20 <= 0.9 x ctl on both seeds, tangential and v-dependent output rms < 5% of the radial output on gravity data (it should learn that truth has none), harness dE rows reported (gate FAIL counts as FAIL). Kill: err@20 >= 0.95 x ctl (D4 prediction) or |dP| above ctl's. Generalization claim needs its own test (a drag or contact pair family) and is not covered by this criterion.
Predicted effect: err@20 0..-10% on gravity data (D4's best paired ratio .92); non-null only on non-gravity pair laws (UNTESTED).
Risks: spurious freedom on gravity data (24% v-dependence already present in the grid branch); energy rows; extra cost.

### R4. Reciprocal (symmetrised) neighbour list

Mechanism. Each body keeps its k nearest within pp (sf:269-275). Pair (i, j) is dropped from i's term whenever j is not among i's k nearest even when i is among j's, so the pair force is applied one-sided and momfix redistributes the leftover over all N bodies (sf:482-484). Build the union list (pair kept if either side selects it, capped at 2k per body by deterministic nearest-first selection) and evaluate each unordered pair once, applying +-F to both ends via index_add. Cost O(N k), bound 2k per body.
Hooks: `pp_acc_cell` (sf:241-276) and dense path (sf:366-376): after top-k, scatter the (i, j, w) triples, symmetrise, `index_add` to both bodies.
Why nn<1: only in dense cores. substep-experiments.md reports 17-19 neighbours with r<2 per body in cl scenes (above knn=16) and 155-170 in bh1000, versus 1-4 in ab: in expB scenes (where the 95%-from-nn<1 finding was measured) truncation is essentially absent, so R4 cannot explain expB error. Expected relevance: clusters and the bh scenes, plus the OOD density rows.
Constraints: O(N) with cap 2k; tileable yes; generalizes yes; interpretable neutral; learned dynamics yes; no new structure beyond making an existing implicit symmetry exact (reciprocity of the pair term, which is the current structure; if R3 is adopted the reciprocal evaluation applies to the radial part only); momentum improved (less momfix leakage); non-conserving yes.
Step 0 (eval-only, cheap): on cl and bh1000 scenes measure (a) the fraction of in-range pairs present one-sided, (b) the weighted force (sum W F) lost to one-sidedness and to the k cap, and (c) momfix's mean-acceleration subtraction magnitude relative to rms |a|. Proceed only if (b) is > 2% of the nn<1 squared force error in cl scenes; kill otherwise.
Pass / kill (if proceeded): single change vs ctl, cl err@20 <= 0.9 x ctl on both seeds, ab not worse (> +5% is a kill), |dP| unchanged or lower. Predicted effect: cl -0..-10%, ab null (UNTESTED).
Risks: variable per-body list lengths break static graph shapes unless padded to 2k; truncation of the cap changes which pairs drop.

## 5. Considered and not recommended

| idea | verdict | reason (evidence) |
|---|---|---|
| Hard-wired antisymmetric / one-eval-per-pair pair law, or learn V(r) and force = -grad V | reject as a constraint | the pair term is already central and reciprocal (section 1), so no accuracy is gained, and the no-hard-coded-conservative-forces rule forbids adding it. In 1-D radial form V(r) and F(r) are interchangeable, so the potential parameterization only matters if non-central remainders are excluded; R3 keeps them. Tension: the grid branch is already potential-valued (`potential=True`), accepted before the rule, so the rule is satisfied only in the pair branch via R3 |
| Local refinement patch / multi-resolution grid / adaptive softening grid | reject | multilevel adaptive refinement was 3-10x worse than dense at equal budget (scatter-field-architecture.md); mesh resolution is not what limits r<1 pairs (the pair term owns them); refinement cost follows density; R1 gets the benefit of sub-cell accuracy without cells |
| Learned per-body softening / length scale | reject for this problem | truth eps is fixed 0.5; OOD softening mismatch is a generalization issue (scatter-ood.md: sharp optimum at 0.5, an `epsin` input exists, sf:111-112), not the nn<1 error in-distribution |
| Sub-cell dipole channels (m dx, m dy) into the U-Net | low priority | gather is bilinear (sf:172-181) so the U-Net field cannot cancel arbitrary within-cell structure; R1 does it per pair |
| Galilean-relative momentum channels (m (v - local mean v)) | not close-pair specific | removes bulk-drift dependence only; v_rel between close bodies is dispersion and stays. Covered by the untested Galilean-boost augmentation (codebase-proposals P4) |
| Interlaced two-grid mesh | not close-pair | 2x mesh cost, deterministic version untested for dE; random jitter already raised dE x5.8 (D6). R1 is the in-range analogue at lower cost |
