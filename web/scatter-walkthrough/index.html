Bounce scatter-field walkthrough

One forward pass of the learned grid model, as 3D objects. Run the live model

About and caveats
  • This is one real traced tick of the JavaScript port in a web worker (about 0.5 s), not a live simulation.
  • The port assumes unit mass for every body. Bodies outside the 64 x 64 arena get no grid force.
  • UNet channels are not individually interpretable: the scrubber shows raw channels, not named features.
  • The kernel convolution and the pair term are not softmax attention.
  • Velocity Verlet runs the force pipeline twice per tick; one pass (the end-of-tick one) is shown.
  • Layout sizes are schematic: every field covers the whole arena, drawn at different scales.
